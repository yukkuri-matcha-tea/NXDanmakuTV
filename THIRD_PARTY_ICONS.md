# Material Symbols
The ms_*.xml vector drawables are Material Symbols Rounded by Google.
Source: https://github.com/google/material-design-icons/tree/master/symbols/android
Apache License 2.0: https://github.com/google/material-design-icons/blob/master/LICENSE
Only symbols used by the application are bundled. Default optical size is 24,
weight 400, grade 0. Navigation uses FILL=0 and FILL=1 variants.
The source tint attribute is removed so Compose MaterialTheme supplies icon colors.
Launcher artwork is the existing NXDanmakuTV television/comment identity redrawn
for adaptive safe zones; it is application artwork, not a Material Symbol.
